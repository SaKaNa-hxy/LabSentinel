# 实验服公开素材微调数据

这个版本补充 54 张从 Wikimedia Commons 筛选的照片。训练使用 42 张公开照片和 900 张已有的完整标注图，验证保留 12 张公开照片和 240 张已有验证图。公开照片按署名来源分组，训练与公开验证之间无相同署名组。

公开照片经过目视筛选。衣服框来自模型提议和人工修订，实验服和普通衣服沿用原数据的类别 5 和 9。训练入口在公开照片上只计算这两个类别的分类损失，同时使用原数据训练全部 12 类。普通训练入口会把未标注类别视为背景，因此本数据的训练清单配合专项入口使用。

训练清单中每张公开照片出现六次。900 张已有样本包括 660 张原图和 240 张上半身裁剪图。已有数据的样本按冻结清单取用，最终测试仍使用原来的 735 张图。用户提供的四段视频作为独立诊断素材。

- `public_sources.json` 记录每张照片的原页面、作者、许可、处理方式和划分。图像和标注框保存在本地数据包。发布素材或裁剪版本时按逐文件许可执行。
- 本地数据包的 `verification.json` 记录用于训练、验证和测试的图像及标签哈希，以及公开照片与既有数据、视频抽帧和已接收公开图的感知哈希距离。
- 本地数据包的 `public_val.txt` 是专项验证清单。使用标注框匹配统计三种衣物的正确率，权重筛选只依据这份清单。

专项训练入口为 `asset/diagnostics/coat_public_20261112/train_pilot.py`。训练、权重筛选和复测结果在对应诊断目录保存。
